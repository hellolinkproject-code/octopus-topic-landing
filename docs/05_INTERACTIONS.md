# JavaScript 상호작용 명세

## 1. 모바일 메뉴

- 1024px 이하에서 긴 다국어 메뉴가 겹치지 않도록 햄버거 버튼 표시
- 클릭 시 내비게이션 열기/닫기
- 메뉴 선택 시 자동 닫기
- `aria-expanded` 값 변경
- ESC 키로 닫기

## 2. 부드러운 이동

- `href="#section-id"` 링크 클릭 시 해당 섹션으로 이동
- 고정 헤더 높이를 고려
- `prefers-reduced-motion` 사용자는 즉시 이동

## 3. FAQ 아코디언

- 질문 버튼 클릭 시 답변 열기/닫기
- `aria-expanded`, `aria-controls` 사용
- 한 번에 여러 항목을 열 수 있어도 됨

## 4. 체험 신청 폼

### 필수

- 닉네임
- 이메일
- 목표 급수

### 검증

- 빈 값 확인
- 이메일 형식 확인
- 목표 급수 선택 확인
- 오류 메시지를 해당 입력 아래 표시
- 오류 발생 시 첫 오류로 포커스 이동

### 성공

- 데이터를 `localStorage`의 `octopusTrialApplication`에 저장
- 성공 메시지 표시
- 키보드로 닫을 수 있는 성공 모달 표시
- 실제 서버로 전송하지 않았다는 안내 유지
- 같은 이메일 재입력 시 덮어쓰기 전에 안내

## 5. CTA 피드백

- CTA 선택 시 체험 신청 폼으로 부드럽게 이동
- 도착한 폼에 짧은 강조 효과 표시
- 모션 감소 설정에서는 강조 애니메이션 제거

## 6. 등장 효과

- IntersectionObserver 사용 가능
- `data-reveal` 요소에 클래스 추가
- 모션 감소 설정에서는 효과 제거
- 콘텐츠를 숨긴 상태로 오래 두지 않음

## 7. 현재 연도

푸터의 연도를 JavaScript로 자동 설정한다.

## 8. 언어 변경

- 헤더의 언어 선택기에서 한국어, 영어, 중국어(간체), 베트남어, 몽골어, 일본어를 선택할 수 있다.
- 페이지 제목, 주요 카피, 내비게이션, FAQ, 폼, 오류 및 성공 메시지를 함께 변경한다.
- 히어로 일러스트 안의 미션·포인트·첨삭 레이블과 이미지 대체 텍스트도 함께 변경한다.
- 선택한 언어는 `localStorage`의 `octopusLanguage`에 저장한다.
- 저장된 언어가 없으면 지원되는 브라우저 언어를 우선 적용하고, 그 외에는 한국어를 사용한다.
- `html` 요소의 `lang` 속성을 선택한 언어에 맞게 변경한다.
