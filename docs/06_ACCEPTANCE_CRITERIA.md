# 완료 기준 및 테스트 항목

## 기획

- [ ] 문제 → 해결 → 기대효과가 구분된다.
- [ ] 타깃 사용자가 명확히 표현된다.
- [ ] 핵심 메시지가 첫 화면에서 보인다.
- [ ] 1차 CTA와 2차 CTA가 존재한다.
- [ ] 포인트가 내부 리워드임을 설명한다.

## HTML

- [ ] header, nav, main, section, footer를 사용한다.
- [ ] 하나의 h1만 존재한다.
- [ ] h2와 h3 제목 순서가 자연스럽다.
- [ ] 모든 이미지에 alt가 있다.
- [ ] form input에 label이 연결되어 있다.
- [ ] 버튼과 링크의 역할이 올바르다.

## CSS

- [ ] CSS 변수로 컬러를 관리한다.
- [ ] Flex 또는 Grid를 사용한다.
- [ ] 360px에서 가로 스크롤이 없다.
- [ ] 768px에서 레이아웃이 자연스럽다.
- [ ] 1280px에서 최대 너비가 지나치게 넓지 않다.
- [ ] 버튼·카드의 라운드와 여백이 일관된다.
- [ ] 텍스트 대비가 충분하다.
- [ ] 키보드 포커스가 보인다.

## JavaScript

- [ ] 한국어, 영어, 중국어, 베트남어, 몽골어, 일본어 전환이 작동한다.
- [ ] 선택한 언어가 브라우저에 저장되고 다시 방문했을 때 유지된다.
- [ ] 언어 변경 시 제목, 본문, FAQ, 폼 오류와 성공 메시지가 함께 변경된다.
- [ ] 언어 변경 시 html lang과 접근성 레이블이 함께 변경된다.
- [ ] 모바일 메뉴가 작동한다.
- [ ] 메뉴 링크 선택 후 메뉴가 닫힌다.
- [ ] FAQ가 키보드로 작동한다.
- [ ] 빈 폼 제출 시 오류가 표시된다.
- [ ] 잘못된 이메일이 차단된다.
- [ ] 정상 제출 시 성공 메시지가 표시된다.
- [ ] 정상 제출 시 성공 모달이 표시되고 ESC 키로 닫힌다.
- [ ] CTA 선택 시 체험 신청 폼으로 이동하고 도착 피드백이 표시된다.
- [ ] 데이터는 localStorage에만 저장된다.
- [ ] 현재 연도가 표시된다.
- [ ] JavaScript 오류가 콘솔에 없다.

## 콘텐츠

- [ ] 실제 이용자 수나 성과를 조작하지 않는다.
- [ ] 공식 TOPIK 점수라고 표현하지 않는다.
- [ ] 현금 출금 가능 서비스처럼 표현하지 않는다.
- [ ] 한국어 문장이 짧고 쉽게 읽힌다.

## 배포

- [ ] index.html이 루트에 있다.
- [ ] 이미지 상대 경로가 정상이다.
- [ ] Vercel 배포 후 모든 섹션이 열린다.
- [ ] 모바일에서 CTA와 폼을 사용할 수 있다.
- [ ] 배포 URL을 과제 제출 문서에 기록한다.
