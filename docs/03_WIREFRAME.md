# 와이어프레임

## 전체 구성

```text
┌─────────────────────────────────────┐
│ Header: 로고 / 메뉴 / 무료 체험       │
├─────────────────────────────────────┤
│ Hero                                │
│ 왼쪽: 배지, H1, 설명, CTA             │
│ 오른쪽: 학습→포인트→첨삭 시각화        │
├─────────────────────────────────────┤
│ Problem: 문제 카드 3개                │
├─────────────────────────────────────┤
│ Solution: 이용 단계 3개               │
├─────────────────────────────────────┤
│ Features: 기능 카드 4개               │
├─────────────────────────────────────┤
│ Reward Loop: 학습 순환 흐름            │
├─────────────────────────────────────┤
│ Benefits: 기대효과                    │
├─────────────────────────────────────┤
│ Target: 주요 사용자                   │
├─────────────────────────────────────┤
│ FAQ 아코디언                          │
├─────────────────────────────────────┤
│ Final CTA + 체험 신청 폼               │
├─────────────────────────────────────┤
│ Footer                              │
└─────────────────────────────────────┘
```

## 데스크톱

- 최대 너비: 1180px
- 히어로: 2열 55:45
- 문제·해결: 카드 3열
- 핵심 기능: 카드 4열 또는 2×2
- 최종 CTA: 설명과 폼 2열

## 모바일

- 최소 360px
- 모든 섹션 1열
- 헤더 메뉴는 햄버거 버튼
- CTA 버튼은 화면 너비에 맞춰 세로 배치
- 학습 루프는 세로 흐름으로 전환
- 기능 카드는 가로 스크롤보다 세로 목록을 우선

## 시선 흐름

1. 무엇을 제공하는 서비스인지 이해
2. 내 문제와 관련 있는지 확인
3. 어떻게 해결하는지 이해
4. 기능과 혜택 검토
5. FAQ로 의심 해소
6. 무료 체험 신청
